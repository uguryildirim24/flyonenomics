# Identical-input CUDA/Brian2 protocol

Frozen before outcome runs, 2026-09-26. This is an engine comparison, not a new biological experiment. No pass threshold or parameter fitting.

- Full MaleCNS network and unchanged item 155 substrate, parameters and dopamine-reference clamp. Two seeds, 501 and 502; intact rest and outgoing GABA disconnection, each 12 seconds. Both conditions keep dopamine clamped to isolate LIF arithmetic, unlike the earlier free-dopamine knockout tour.
- Independent NumPy PCG64 streams seeded directly with 501 and 502 generate Binomial(100, 0.001) multiplicities for every 0.1 ms tick of every nonzero-background target. Draws include refractory ticks; rejection depends on the simulated target state. One saved event stream per seed is reused across engines and conditions. Nonzero records encode tick, target and multiplicity; files and target ordering are hashed. No within-engine random input is active during replay.
- Brian2 engine source is untouched. The comparison harness disables its PoissonInput and zero-rate PoissonGroup and adds a zero-delay SpikeGeneratorGroup/Synapses input. Virtual sources encode target and multiplicity, so each source fires at most once per tick. A multiplicity-k event adds k times that target's original background weight in the synapses slot. CUDA receives the same saved events via a deterministic background path. This preserves the binomial-count distribution, rather than replacing it with Poisson counts or discarding simultaneous events.
- Settle [0,2) s; report per-neuron counts separately in [2,7) and [7,12) s (ON/OFF labels are window names only: no stimulus switches). Also report their sum and paired GABA-minus-intact count differences. Save all output neuron/tick pairs including settling; compare canonically sorted tick/neuron sets to locate the first unequal output tick. Report numerical state differences only if inspected; first spike divergence is not the first floating-point difference.
- For each seed/condition/window: exact-count matches out of all 162,517 neurons, signed difference histogram, mean/mean absolute/RMS/min/max differences, absolute quantiles, and side-by-side rates for every rest and courtship readout group. Report exact spike-train equality or first divergent tick, without inventing an equivalence bound. Archive hashes and run timings accompany the analysis.
- If cheap, benchmark one initialized brain with ordinary stochastic input at 1 ms and 10 ms chunks on L4 after a small host-transfer improvement. Include full count/histogram/first-tick outputs and GPU dopamine; no redesign or body-loop claim.
- Modal only under MODAL_PROFILE=flyonenomics. Each submit prints projection and checks workspace billing summary; separate receipts reserve bounded calls against a $5 lane cap and $30 workspace band. Include failed calls in final metered spend.

The model receives injected input; the fly does not see. Visual input elsewhere is injected at TuBu; this comparison uses dark sensory-background drive only.
